## Not possible without T3 changes

Most of the morning list here is now done through the injected script (composer mentions, theme, knowing the shown thread, events out of the page). What still holds:

- Making T3 open a given file inside its own page from VS Code: T3 has no route for it.
- Inline accept or reject of edits a harness writes directly: only a diff our own tool shows (BACKLOG B22) could get that.
- Events out of T3's page exist only through the injected script, which depends on T3's page structure and may break with a nightly (`t3-facts.json` watches the places it relies on).
