# Keys and menus

| Where | What | Does |
|---|---|---|
| Editor | `Ctrl+Alt+C` | Focus the T3 composer (opens the panel if it is closed) |
| T3 panel | `Ctrl+Alt+C` | Back to the editor |
| Editor | `Alt+K` | Add the selection to the prompt |
| Anywhere | `Ctrl+Alt+T` | Switch thread |
| Explorer, tab, editor | Right-click, **T3: Add to prompt** | Add the file to the prompt |
| Explorer, tab | Hold Shift and drag onto the panel | Add the file to the prompt |
| Problems light bulb | **Fix with T3** | Put the file, line and problem into the composer |
| TODO or FIXME comment | **Implement with T3** | Put the comment into the composer |
| T3 code block | Alt+click **Copy code** | Insert the code at the VS Code cursor |

Nothing is sent by itself: you review the prompt in T3 and press Enter.
