# Start T3

This extension is a client. The T3 desktop app runs the server on this computer, and the T3 panel in VS Code connects to it.

- Run **T3: Start the T3 desktop app**, or start T3 yourself.
- When T3 is not running, the panel says so and shows a **Start T3** button.
- Closing VS Code does not stop T3. Your threads keep running.
