# Pair this computer

VS Code signs in to T3 like the phone does, with a pairing link.

1. In T3 open Settings, Connections, Create link. Label it VS Code.
2. Paste the link or the code into the panel's pairing field.

A session lasts 30 days. Tick **Manage access** when you create the link, and the panel renews the session by itself. **T3: Forget the pairing** signs out.
